### 📦 Featured Project: ParcelHub

**AI-Augmented Parcel Escrow & Visual Logging System**

ParcelHub transitions traditional, synchronous last-mile deliveries into a secure, asynchronous workflow for workplace staff and community residents:

- **Asynchronous Proxy Receiving:** Pre-registers inbound deliveries with receipt uploads, eliminating missed drops.
- **AI-Augmented Visual Documentation:** Employs computer vision during turnover to log parcel condition and maintain an audit trail.
- **Dual-Factor Authentication:** Safeguards parcel handovers via personal MPINs and dynamic QR codes.
- **Cross-Platform Solution:** Built with Next.js (Admin Management Dashboard), React Native (Client/Staff Mobile Apps), Supabase, and PostgreSQL.
